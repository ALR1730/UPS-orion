# 📚 Índice de Documentación Scrum - Proyecto Final ORION (MVP)

Bienvenido a la documentación oficial del proyecto **ORION MVP** para la prueba piloto de optimización de rutas de reparto. Toda la arquitectura ágil y técnica está alineada con el documento maestro [documento_entregables_scrum (1).md](../documento_entregables_scrum%20%281%29.md) y el tablero de Jira Software.

---

## 🎯 Información del Sprint 1

* **Product Goal:** Habilitar una plataforma digital centralizada y ligera que permita validar, en un entorno piloto controlado de 5 conductores y 1 zona urbana durante 6-8 semanas, si el ordenamiento automatizado de paradas reduce entre un 8% y 10% los kilómetros recorridos.
* **Sprint Goal:** Registrar artículos masivamente por CSV, optimizar la secuencia lineal, visualizar la hoja de ruta en móviles con enlaces GPS y consolidar las métricas de odómetros en un reporte para el supervisor.
* **Total Story Points:** 14 SP (7 Historias de Usuario completadas al 100%).
* **Tablero Jira:** [Acceso al Tablero SCRUM ORION](https://itla-adm.atlassian.net/jira/software/projects/SCRUM/boards/1)
* **📘 Documentación Técnica Integral:** [Manual de Arquitectura y Especificación Técnica (DOCUMENTACION_TECNICA.md)](DOCUMENTACION_TECNICA.md)
